# ITAI 4376 – AI Controls in Robotics

## 📘 Course Overview
This repository contains coursework, assignments, labs, and project materials for **ITAI 4376: AI Controls in Robotics**. The course focuses on the integration of artificial intelligence techniques with robotic control systems.
